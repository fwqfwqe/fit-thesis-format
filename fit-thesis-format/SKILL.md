# 福州理工学院论文格式：完整执行与双引擎验收

完整任务从原稿副本完成全文处理和验收，不止生成清单或样式稿。一次委托允许内部多轮修复，不能让用户逐个指出遗漏。只审核或局部修改时遵守用户范围。

以快、准、好、省为共同目标：先一次盘点全文，再批量修改并验证实际页面；局部返修用局部修复路径。依据是原稿、书目、学校模板和实际显示，不以测试数量代替质量。只对有修改、失败或未解决疑点的部分扩大复核；哈希完全一致的真实观察才可复用，不能重复探测与渲染来增加工作量。

已有成品返修时，先定位用户正在看的版本并盘点具体缺陷。若正文结构已经正确，优先在副本中一次完成来源绑定的局部修复，再统一刷新目录和实际导出。使用现有任务的next/submit/resume继续；遇到能力或缓存错误先修具体原因，不反复新建run并重做整篇和四次能力探测。修复范围以外的对象须做完整性对照，新的排版输出仍须实际看图。

## 启动与推进

确认用户指定的原稿是真实可读文件，不以“最新文件名”擅自换稿。读[规则来源](references/rules-v10.json)、[格式细则](references/format-requirements.md)和[执行合同](references/v10-execution.md)。`style-spec.json`是样式数值的唯一来源。

使用当前宿主Python运行 `scripts/thesis_job.py --request -`，标准输入为：

```json
{"action":"run","source":"原稿的绝对路径.docx","work_dir":"新的绝对工作目录"}
```

读取返回的状态与待办。通过 `next` 取得任务，完成语义决定或实际页面复核后 `submit`，再 `resume`。具体参数见[agent-tools.json](agent-tools.json)及脚本帮助。不要猜任务字段，也不要跳过未完成状态。

自动程序负责确定性修改，宿主智能体负责上下文判断与实际看图。语义或视觉任务返回宿主并不等于要向用户重新授权：先自行阅读、操作和核对，仅真实缺失事实才集中提问。继续处理不依赖答复的事项。

## 全文覆盖

所有段落、表格及其他文档区域均须有决定。长文可分批和断点继续，不能抽样替代全文。标题依文字及上下文确认，不单凭字号、样式名或数字开头猜测。

| 部分 | 必须处理及复核 |
|---|---|
| 前置 | 学校封面、完整承诺书、中英文摘要及关键词、两级自动目录 |
| 正文 | 四级标题、真实编号、中英文混排、可修改样式、缩进和间距 |
| 页面 | A4边距、前置罗马页码、正文1起续号、按显示页码的奇偶页眉 |
| 图表 | 表题在上图题在下、宽度列宽、表头与行组、续表及表注 |
| 公式 | 可编辑结构、普通段落中心及右制表位、完整标签、足够行高 |
| 文后 | 完整引文标记上标、作者年份基线、文献格式、附录在致谢前 |

区分封面表、数据表、复杂文字表、Panel表和公式布局表。Panel保留分隔线、系数/标准误组合及表注，不强改全网格或删除全部内线；也不强加给其他表。

## 原稿与内容保护

在原DOCX副本上定点修改，不能抽取文字重建全文。保护OMML/OLE、图片、数据、嵌入对象、脚注尾注、书签、链接、真实批注和修订。新建示例是另一种任务。

完整格式任务包含必要的学校组件、编号显示、目录刷新、页眉页码、排版空白和附录位置转换；每项必须记录及验证，不假称全部字符不变。明确逐字不变时限定操作范围。

不改研究论述、数据和公式含义，不猜文献、身份、签名或日期。普通英文词间空格、代码缩进、空单元格及承载书签、分节、对象的空段不可一律删除。不能把英文缩写和人名自动转为数学对象。

学校组件从净化模板复用；不带入范文文字、示例姓名、日期及历史批注。原稿真实批注与修订仍受保护。数字、符号或原件不清晰时保留并说明，不能猜写。

封面及承诺书保留模板自身的表宽、列网格、行高、字体及段距，不能按正文页宽拉伸或逐段覆盖成正文样式。信息字段按标签匹配，不能按行号顺序硬填。封面题目与承诺书中文题目使用本稿已确认题目；未知身份、签名、日期留正常填写空位。作者有[n]但没有年份同样必须检查，年份只从已经核对的本稿书目取得，不能因扫描器只认“作者（年份）”而漏掉。

## 完成条件

同一最终DOCX须在Word、WPS分别通过：真实导出、目录对应实际页码、编号连续、公式可编辑、表格完整、无异常空白页或裁切。实际打开两套导出的全部页面；生成图片、抽取文字、批量勾选pass都不等于看过页面。

发现问题仍检查后续页，再修复同类问题并复验相关对象和后续分页。最终证据绑定最终文件；重新保存后不能沿用旧哈希。只有逐页图像完全相同才可复用已有真实观察。

实际页面修复通过[来源绑定修复接口](references/layout-repairs.md)提交：包括段落分页与间距、图片等比适配、根据真实行页确定的续表断点、题注目标和已核对的普通文字公式转录。使用原稿定位及实际源哈希，不能绕开阶段链修改终稿。旧OLE及图片公式保持原对象，不能猜测其内容；需要宿主取得可核对原件或实测编辑能力。

内容、可见性、对象关系、语义格式均须校验；不能仅检查文字是否还在。再次运行不得继续新增封面、编号或页眉部件。不能靠任意白名单、重设基线、删检查项取得通过。

## 跨智能体与规范来源

相同Python内核通过CLI/JSON供不同宿主使用，不硬编码智能体品牌或私有路径。启动前实测字体、公式、字段和两种软件的导出能力；软件注册项存在不代表可用。缺WPS不能宣称双验收完成。无文件执行工具的纯聊天环境只能提供审核建议；不擅自上传论文以获取外部渲染。

现有配置适用于福州理工学院经济管理学院，依据附带范本及2026-10-29用户确认要求。致谢最后、无框且不用布局表的公式、正文作者写法保持当前默认；不声称取得新版官方文件或覆盖全校所有学院。

旧工具是受限底层动作：prepare只准备任务，thesis_format只做基础样式。它们成功不替代完整流程。[旧工作流](references/workflow.md)的逐字保护限制不能用来跳过完整任务已授权的空白、目录和结构修复。

## 交付

交付可编辑DOCX和简短真实修改说明。未通过时准确报告未完成项，不能称完整验收。内部日志、映射、QA图和新增审核批注不塞进论文。
