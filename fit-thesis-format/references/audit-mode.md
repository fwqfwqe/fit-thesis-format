# 只读格式审核

当用户把论文交来要求“先看看哪里不符合、哪里要改”，先执行审核模式，输出论文外的中文问题清单。审核不是改稿，不更新目录或其他字段，不在正文插入批注、提示或占位词，也不覆盖输入文件。

审核命令（Python 运行时使用本机依赖加载结果）：

```text
python scripts/format_audit.py "论文.docx" --json "格式审核.json" --markdown "格式审核.md"
python scripts/format_audit.py "论文.docx" --mapping "role-map.json" --title "已确认的本论文完整题目" --json "格式审核_精准.json" --markdown "格式审核_精准.md"
```

报告文件不得与源文件同路径，脚本拒绝覆盖已有报告。它在读取和结束时比较论文完整字节；SHA-256 绑定在报告里，可证明本次只读检查的输入版本和输入未变。显式 `role-map.json` 沿用 `thesis_format.py` 的段落及表格映射结构，并必须与这份论文 SHA-256 一致；不允许给后续版本沿用旧定位。每个段落有 `p000001`，表格有 `t0001`，节有 `s001`。这些是 XML 定位，不是实际页码。

## 报告怎么用

每项包含严重程度 `severity`、项目 `category`、定位 `location`、实际证据 `actual`、目标 `expected`、建议 `recommendation`、处理类型 `status`、识别置信度 `confidence`。JSON 保留全部证据；中文 Markdown 先列最多 8 类首要问题，再按规则归组，每类列总数和最多 5 个典型定位，其余全量定位见 JSON，避免几百个重复字号问题淹没封面、页眉和公式缺陷。不能仅报告“样式名不对”。

- `auto_fixable`：已有明确语义角色后可以修复纯格式，例如字体字号、行距、首行缩进、页边距、重复表头、命名样式继承或明确授权的页眉页脚。它表示可安排修复，不表示审核已经修改。
- `requires_content_authorization`：新增/改动字符、缺失摘要或承诺书、目录重建及字段更新、手打标题编号转自动编号、公式标签补“公式”和动态编号迁移。应核对是否已有明确授权及转换记录；已有授权继续执行，不要求重复询问。这些必须在内容不变核验中单独界定；不能以“符合学院要求”为由静默执行。
- `requires_role_review`：依启发式识别的角色、未确认的数据表类型、可能是数组/数据的 `[n]` 等，先让执行代理读原文确认，不默认都按文献或标题处理。
- `requires_render_review`：实际奇偶页、页码连续、空白页、公式裁切、表格跨页、图表重叠等，必须经原生 Word/PDF 逐页核查。不能把静态审核通过写成“格式全部合格”。

## 静态审核范围

1. 按本技能 `style-spec.json` 检查每个已识别段落的**有效**中西文字体、字号、行距、段前段后、缩进、对齐、大纲级别、标题另起页和与下段同页；结合文档默认值、样式继承、字符样式、段落/文字直接格式及主题字体。数学对象内部字体不盲目统一。
2. 检查可见、未隐藏且未锁定的语义样式，以及会阻断用户手调样式的直接字体/字号和段落属性；外观相同而属性被写死也要指出。Word 保存时可改写 styleId，仍按已确认的语义样式名识别；继承字符单位缩进时，Word 写入的 twips 后备值不生效，不误报为阻断。原生封面承诺书局部布局、公式最小行高、对象引入段跟随、另起页及图表前后留空在 `style_layout_exceptions` 或 info 中说明，不为统一而清除。
3. 检查学校封面和诚信承诺书的可定位文字证据，中英文摘要/关键词及顺序；缺作者/日期/签名不猜填。承诺书里的校名不借作前一页封面证据；学校范本封面校名在校徽图片内，匹配原生模板媒体 SHA-256 可作证据。其他学校标识图片不能靠 OCR 或文件名猜认。没有识别到时写“未识别/待确认”，不得断言已找到完整合格封面。
4. 检查真实 TOC 域、两级深度和第三层目录条目。手打页码或单独 PAGEREF 不能冒充完整自动目录；更新域会改变目录缓存文字，要有范围授权。
5. 检查标题的有效 `numPr`、真实多级 `numId` 和 `numbering.xml`，目标为 `一、`、`（一）`、`1.`、`（1）`，四级大纲 0/1/2/3。仅文字前缀不能称“自动编号”。不同正文列表、章号递增/子级重启仍需 Word 实际显示复核。
6. 检查每节页面、有效及显式 default/even/first 页眉页脚引用、链接继承、奇偶开关、题目与固定学校文字、真实 PAGE 域、前置 upperRoman 从 I 起和正文 decimal 从 1 起、后置部分续号。条件 IF 页眉不能代替用户现在要求的真实奇偶页眉引用。
7. 仅对映射确认的数据表核查居中、三线/复杂表边线、1.5/0.75 磅线宽、重复表头、固定行高和表题在上。封面承诺表、附录代码容器和数据表内的数学符号不当作独立公式。按用户最新要求，已审定的独立公式**不能用表格或文本框定位**，即使无打印边框，Word 虚线网格也不是用户接受的版式；报 `math.table_layout_disallowed` / `math.textbox_layout_disallowed`。将其主体、标签、字段和书签原样移到普通段落并去除空布局容器属于格式迁移，不能归为删除学术内容。真实跨页和“续前表”仍走渲染/内容范围判断。
8. 检查普通段落中的原生公式 OMML、旧式 Equation/MathType OLE、图片/纯文本候选、完整 `公式（x-x）`、SEQ 及 REF/字段完整性、公式固定行高裁切风险。支持中心/右边界制表位分别定位主体和动态标签，不硬要求整段居中；最终看主体、标签实际位置及断行。显式表格/单元格/段落可见边框报 `math.visible_border`，非打印虚线网格不冒称打印边框。存在 OLE 仅证明类型，须实际打开确认编辑器可用；图片不能声称公式可编辑。普通字母是否正文变量、上下标数学意义是否正确不能靠模式自动保证。
9. 谨慎定位正文 `[n]` 的整体上标、文末编号基线、括号年份基线；不改作者、年份或引用位置。数组/代码/数据须排除，参考文献类型标识 `[J]` 等不作上标。
10. 按用户最新要求，后置部分顺序为参考文献、**已有附录**、致谢，最后实质部分为致谢。实际目录条目不作结构标题证据；缺失或未识别致谢报 `structure.acknowledgement_missing_or_unconfirmed`，已有致谢却不是最后报 `structure.acknowledgement_not_last`。已有附录全文保留并移到致谢之前，没有附录不能生成；没有致谢不能以改格式为由补写。静态结果只证明已识别标题顺序，最终仍看最后实际打印页。

## 必须接续的渲染审核

最终修改稿需原生 Word 或可信兼容渲染，逐页检查所有页面，并在报告追加实际页码定位、奇偶页眉截图证据、连续页码、自动标题显示、TOC/SEQ/REF 更新后的结果、公式及上下标、表格跨页及图形边界。应以正文**显示页码**判断奇偶，不能凭 PDF 物理页次替代。

如用户仅要求审核，交付问题清单即可；如同时要求修复，按已授权范围继续做，不要重复索要已有许可。源论文文字、对象、媒体、编号迁移前后及允许的封面/承诺书/字段变化分开核验。只有完成静态与渲染审核后才能描述实际通过的部分，仍有未识别或未处理项须如实列出。
