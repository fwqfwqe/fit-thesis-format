`assets/fit-economics-management-template.docx`保留原件，SHA-256为`83dac94cb138ab7b46fb100d9ac05c6e1ab8c7dec986ebefd2e5ca22bf359eac`。document.xml的body直接子节点（0起算）0–8为学校封面，9–13为承诺书，14开始中文摘要；第13节点含前置无编号节的sectPr。克隆前两页时保留校徽drawing/关系/媒体、封面填写横线和合并单元格，并识别组件中的批注、黄色高亮与个人示例值，不能把教学批注留到新论文。

## 编号与允许的转换

学校批注28/30/34/37的四级显示为“一、”“（一）”“1.”“（1）”。模板自身有手打编号，自动编号是用户追加的可编辑功能：以学校的显示形式创建Word多级列表，而不是照抄手打实现。正文章样式为大纲0，以下依次1、2、3；目录只显示大纲0和1。

原文转换必须逐个记录`原段落/原编号/标题名称/目标级别/目标显示编号`，只移走已确认的编号前缀并绑定numPr，不删除以数字开头的普通句子。即使显示编号相同，XML文字也会变化；核验应比较Word实际显示编号与保留的标题名称，研究内容另逐字对照。如果改变章节编号制式，交付如实说明，不能声称编号字符完全未变。

公式与图表的章节数字仍为阿拉伯数字。新建helper用隐藏SEQ FITChapter追踪章数，并在每章重置独立SEQ FITEquation，标签内引用当前章SEQ与公式SEQ；正文用REF指向完整标签书签。隐藏章域必须随章标题一起增删/移动。新增章时复制一个完整现有章标题后修改标题文字，或通过helper创建，不能只套样式却不带章域。插入、删除、移动后更新域，核验章号、顺序与REF；不能只用Python常量替代动态域。STYLEREF不能将中文章号转换成阿拉伯的原生Word实测及完整API见[native-academic-controls.md](native-academic-controls.md)。

## 可编辑公式和上下标

批注53规定编号“公式（2-1）”；59要求正文变量、字母、公式全部用数学编辑器；60–62说明上下标和表达式。原模板为旧OLE方程，新建实例采用原生OMML可满足编辑器功能。模板没有规定数学字体字号硬值；本示例选择Cambria Math12磅，并提供可手调数学样式。

用m:sSub/m:sSup/m:sSubSup表示上下标，m:f表示分式、m:rad表示根式、m:nary表示求和及上下限。在Word中能单击出现“公式”功能区并编辑是验收条件；统计OMML标签只能证明结构存在，不能证明数值和含义正确。对象不能为只剩预览图的坏OLE；遇旧对象需确认打开可编辑。

图片/普通文本转公式仅对逐个审核过的表达式执行，记录源位置、符号串及结构，原图保留内部备份，核对变量、下标、幂次、分母、括号、希腊字母、正负号和等号。不可识别的变量不要猜；报告待核对对象。按用户最新要求，独立公式使用一个普通段落：中心制表位放原生OMML表达式，右对齐制表位放完整动态“公式（x-x）”标签。段落和数学对象没有边框，也不处于表格或文本框内；不能只隐藏Word网格线。标签文字可通过“论文-公式编号文字”字符样式调整，数学内容通过“论文-数学变量”字符样式调整。移动已有数学节点、域和书签时完整保留，不转成字符串或图片。

## 后置部分顺序

这位用户明确要求致谢是最后一部分，优先于原范本批注中“附录在致谢后”的顺序。实际顺序为结论与展望、参考文献、已有附录（如有）、致谢；目录也须同步。没有附录就不新建，有附录则整块移动至致谢之前，保留原有全部文字、图表、数学对象和代码。此操作在转换记录中注明原位置和新位置，不能当作删除附录的授权。

## 分节与页眉页码

用真实even/default页眉页脚引用，全局evenAndOddHeaders开启，各节关闭不需要的titlePg、断开不应继承的前置页眉。摘要、英文摘要、目录无正文页眉；罗马页码从I连续。正文重启1并且参考文献、致谢、附录续号，两种页脚均为PAGE域。

如果罗马节最后的物理页序与正文逻辑1的奇偶不匹配，Word可能插入无编号对齐页，原模板也有此行为。这不是批注明确的校规。可审慎测试连续分节配合首段段前分页，或保留已诊断的对齐页；必须用Word实际渲染核对，不能只删掉空段或切掉节。用户需要无对齐页时应针对该文档解决，不能用静态单一页眉冒充真实奇偶页不同。

## 新建实例调用

```python
import academic_numbering as A
A.install_styles(doc)
n = A.ThesisNumbering(doc, authorized_new_document=True)
n.heading('绪论', 0)
n.heading('研究背景', 1)
paragraph = doc.add_paragraph(style='论文-正文')
A.append_math(paragraph, A.subscript('x', 'i'))
n.equation(A.fraction('a', 'b'), bookmark='EqOne')
A.add_equation_reference(paragraph, 'EqOne', '公式（1-1）')
```

区域计划覆盖已建立的所有分节；configure_running_furniture之前先完成全部分节。安装样式、Word域刷新、逐页核验与手调都要实际验证，quick_validate只检查技能结构。
